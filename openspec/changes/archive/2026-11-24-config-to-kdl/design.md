## Context

Сейчас `src/config.rs` — serde-структура `Config` с `#[serde(deny_unknown_fields)]`, читаемая через `toml::from_str`; `src/paths.rs` заканчивает путь `config.toml`; `README.md` документирует TOML-пример. Прямой `serde` используется только в `config.rs`; `toml` — только там же. Тулчейн проекта — rustc 1.93, `rust-version = "1.89"`, flake прибит к зарегистрированному nixpkgs, поэтому версия новой зависимости обязана собираться на 1.93.

Существующие инварианты `Config`: `video_path` непустой и указывает на обычный файл, `blur_radius` в `1..=64` (дефолт 12), `app_id_prefix` непустой (дефолт `thepaper`), `transcode_codec` необязателен. Их сохраняет спека `thepaper/configuration`; см. proposal.md — Why.

## Goals / Non-Goals

**Goals:**

- KDL v2-документ с плоским списком узлов: одна опция — один узел, значение — единственный аргумент.
- Сохранить имена опций, дефолты, диапазоны и диагностику; ошибка называет путь конфигурации и проблемную опцию.
- Убрать `toml` и прямой `serde` из манифеста, добавить `kdl`.
- Разложить разбор по концептам так, чтобы `config.rs` оставался файлом типа `Config`, а разобранный документ жил отдельным типом.

**Non-Goals:**

- Фолбэк на `config.toml`, автоопределение формата по расширению или содержимому.
- Переименование опций в kebab-case, вложенный блок `thepaper { ... }`, схемы/типы KDL.
- Поддержка KDL v1 и его неоднозначностей.
- Изменение поведения декодера, поверхностей, овервью и game-mode.

## Decisions

**Зависимость `kdl`.** `kdl = { version = "~6.5.0", default-features = false }`. 6.5.0 — последняя ветка с MSRV 1.82; 6.6+ требует rustc 1.95, которого нет ни в проекте, ни в flake. Версия ограничена `~`, чтобы `cargo update` не подтянул несовместимую 6.6. `default-features = false` отключает `span`: позиции узлов не используются, диагностика называет имя опции. `miette` остаётся обязательной зависимостью `kdl` 6.5 (не фичей), но в публичный API проекта не проникает. Альтернативы: обновить flake до rustc 1.95 (выходит за рамки задачи, ломает воспроизводимость окружения); свой парсер KDL на std (нужны комментарии, экранирование строк, числовые формы — неоправданный риск и объём).

**Схема конфигурации.** Плоский документ, имена опций — прежние snake_case:

```kdl
video_path "/home/user/Videos/wallpaper.mp4"
blur_radius 12
app_id_prefix "thepaper"
// transcode_codec "hevc"
```

KDL-идентификаторы допускают `_`, поэтому переименование не требуется. Аргумент — единственное значение узла; свойства и дочерние блоки отклоняются. Альтернативы: kebab-case (`video-path`) — меняет имена сверх перевода формата; вложенный блок — лишний уровень для четырёх плоских опций.

**Разделение концептов.** Новый файл `src/config_document.rs` содержит `ConfigDocument` — владельца `KdlDocument`: конструктор `ConfigDocument::new(text)` парсит KDL и проверяет форму документа (известные имена, отсутствие повторов, ровно один аргумент, отсутствие свойств и детей), метод `value(name)` отдаёт аргумент узла. `src/config.rs` содержит `Config` и семантику: дефолты, типы, диапазон, проверку файла видео. Причина — правило AGENTS: фаза, прорабатывающая собственные данные (`KdlDocument`), получает свой тип и файл; `config.rs` остаётся в районе сотни строк. `ConfigDocument` — внутренний тип, публично не реэкспортируется; `config.rs` импортирует его полным путём `crate::config_document::ConfigDocument`.

**Поля `Config`.** `Config::load` — конструктор с инвариантами, поэтому поля становятся приватными, доступ — геттерами `video_path()`, `blur_radius()`, `app_id_prefix()`, `transcode_codec()`. Потребители `app.rs` и `main.rs` переходят на геттеры. Альтернатива «оставить `pub`-поля» отклонена: файл переписывается целиком, а инвариант, установленный конструктором, по AGENTS требует приватных полей.

**Числа.** KDL хранит целые как `i128`; `blur_radius` приводится к `u32` через `u32::try_from` на границе разбора, без `as`-кастов, затем проверяется `1..=64`. Строки берутся через `as_string`, отсутствие аргумента — ошибка «missing option», аргумент не того типа — «option must be a string/integer».

**Путь.** `default_config_path()` возвращает `.../thepaper/config.kdl`. Явный `--config` принимает любой путь без проверки расширения. `config.toml` не читается: чистый переход повторяет решение изменения `rename-project-to-thepaper`, где фолбэки на старое имя отклонены, чтобы не держать два источника истины.

**Ошибки.** `ConfigDocument::new` возвращает `anyhow::Result` и называет опцию (например, ``unknown option `blur_radius2` ``); `Config::load` оборачивает ошибку контекстом `invalid config <path>`; семантические ошибки `Config` также начинаются с пути файла. Формат сообщений остаётся в стиле текущих (`config <path>: ...`).

**Зависимости.** Из `Cargo.toml` удаляются `toml = "0.9"` и `serde = { ... }` (derive нужен был только `Config`). `serde` остаётся в `Cargo.lock` транзитивно через `zbus` и `niri-ipc`; `Cargo.lock` перегенерируется сборкой.

**Документация.** README: путь `config.kdl`, KDL-пример, новый блок миграции «`mv config.toml config.kdl`, убери `=`, значения оставь как есть».

## Risks / Trade-offs

- [`kdl` 6.6+ требует rustc 1.95 и может приехать при обновлении] → ограничение `~6.5.0` в манифесте плюс зафиксированный `Cargo.lock`; обновление — отдельным изменением вместе с flake.
- [`default-features = false` не убирает `miette`, потому что в `kdl` 6.5 она обязательна] → зависимость остаётся транзитивной, но не попадает в API проекта и не влияет на разбор; проверено `cargo tree`.
- [Существующий `config.toml` перестаёт читаться, приложение падает на старте] → README даёт точный порядок переименования и правки строк; ошибка чтения файла видна сразу и не маскирует переезд.
- [`i128 → u32` на границе] → только `u32::try_from` с отдельной ошибкой; отрицательные и слишком большие значения отклоняются до проверки диапазона.
- [Потеря номеров строк в диагностике после отключения `span`] → сообщение называет опцию и путь файла; для четырёх опций этого достаточно, включение `span` тянет `miette` без пользы для формата.

## Migration Plan

1. Применить изменение, собрать `thepaper`.
2. `mv ~/.config/thepaper/config.toml ~/.config/thepaper/config.kdl`; в файле убрать `=` в каждой строке (`video_path "..."`, `blur_radius 12`, `app_id_prefix "..."`, `transcode_codec "..."`) и заменить `#`-комментарии на `//`.
3. Обновить внешние вызовы `--config`, если они указывали на `*.toml`.
4. Запустить `thepaper`; ошибка разбора называет путь и опцию.

Откат — `git revert` и обратное переименование файла; пользовательские данные не мигрируют, поэтому откат безопасен.
