## Purpose

Определяет файл конфигурации `thepaper`: язык KDL, состав опций, значения по умолчанию, допустимые диапазоны и диагностику ошибок, чтобы пользователь правил один файл в том же языке, что и конфигурацию компоновщика.

## ADDED Requirements

### Requirement: Формат файла конфигурации

Конфигурация ДОЛЖНА быть документом KDL. Каждая опция ДОЛЖНА задаваться отдельным узлом верхнего уровня, значение опции — единственным аргументом узла; свойств и дочернего блока узел содержать НЕ ДОЛЖЕН. Комментарии KDL ДОЛЖНЫ допускаться. Узлы с неизвестными именами, повторяющиеся узлы и узлы с числом аргументов, отличным от одного, ДОЛЖНЫ отклоняться. Строковые значения ДОЛЖНЫ приниматься как в кавычках, так и в виде KDL-идентификатора; числовые — только целым числом KDL. Нормативный уровень — MUST.

#### Scenario: Полный KDL-конфиг

- **WHEN** файл содержит `video_path "/videos/wallpaper.mp4"`, `blur_radius 24`, `app_id_prefix "custom"` и `transcode_codec "hevc"`
- **THEN** приложение использует все четыре значения

#### Scenario: Комментарии и необязательные опции

- **WHEN** файл содержит комментарии и только узел `video_path`
- **THEN** конфигурация принимается, а `blur_radius` и `app_id_prefix` получают значения по умолчанию

#### Scenario: Неизвестный узел

- **WHEN** файл содержит узел с именем, не входящим в набор опций
- **THEN** приложение завершается с ошибкой, называющей путь файла и неизвестный узел, и не запускает обои

#### Scenario: Повтор узла

- **WHEN** файл содержит два узла `blur_radius`
- **THEN** приложение завершается с ошибкой, называющей путь файла и повторённый узел

#### Scenario: Неверный тип аргумента

- **WHEN** узел `blur_radius` задан строкой или дробным числом
- **THEN** приложение завершается с ошибкой, называющей путь файла и узел `blur_radius`

### Requirement: Опции и значения по умолчанию

`video_path` ДОЛЖЕН быть обязательным и указывать на существующий обычный файл. `blur_radius` ДОЛЖЕН быть целым числом в диапазоне `1..=64`, по умолчанию `12`. `app_id_prefix` ДОЛЖЕН быть непустой строкой, по умолчанию `thepaper`. `transcode_codec` ДОЛЖЕН быть необязательной строкой; при отсутствии кодек выбирается автоматически. Нормативный уровень — MUST.

#### Scenario: Отсутствие обязательной опции

- **WHEN** файл не содержит узел `video_path`
- **THEN** приложение завершается с ошибкой, называющей путь файла и отсутствующую опцию `video_path`

#### Scenario: Значения по умолчанию

- **WHEN** задан только `video_path`
- **THEN** радиус блюра равен 12, а префикс идентификаторов поверхностей — `thepaper`

#### Scenario: Граница диапазона радиуса блюра

- **WHEN** `blur_radius` равен 1 или 64
- **THEN** конфигурация принимается; значение 0 или 65 отклоняется с ошибкой о диапазоне `1..=64`

#### Scenario: Несуществующее видео

- **WHEN** `video_path` указывает на несуществующий файл
- **THEN** приложение завершается с ошибкой, называющей путь конфигурации и путь видео

#### Scenario: Переопределение кодека транскодирования

- **WHEN** задан `transcode_codec`, отличный от автоматически выбранного
- **THEN** транскодирование использует указанный кодек; неизвестный кодек отклоняется с ошибкой, называющей его значение
